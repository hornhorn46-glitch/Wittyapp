# Silent Exit Development Plan

## Current Target

Turn the tutorial level into a convincing first playable slice: readable stealth, believable rooms, clean interaction feedback, and a visual baseline that no longer feels blockout-only.

## Implemented In This Pass

- Close visible gaps around the first locked-door path by widening the physical door panels and aligning them to the trimmed openings.
- Replace oversized factory doorway meshes with hand-built rounded trims, threshold plates, and jamb shadow strips.
- Add an interactable security terminal that gives the player an optional tactical action: disabling the security loop reduces patrol vision and suspicion gain.

## Next Production Passes

1. Environment art: replace remaining simple boxes with room-specific props, decals, ceiling details, cable runs, damage, and believable furniture placement.
2. Stealth readability: add patrol vision hints, better enemy barks, light/dark gameplay feedback, and clearer consequences for sound.
3. Character presentation: improve civilian and hostile animation states, scale, idle motion, head/body turn, and reaction timing.
4. Level design: expand the first mission into a compact rescue route with at least two alternative paths, one locked shortcut, one sound puzzle, and one optional risk/reward objective.
5. Lighting: tune room-by-room baked-style light balance, reflection probes, window bounce, fixture colors, and fog so screenshots read like a coherent night interior.
6. Release path: keep Windows export, automated smoke tests, playthrough captures, and a downloadable GitHub artifact stable after every larger pass.
