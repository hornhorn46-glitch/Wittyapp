...

## Important decisions

## Known issues
- Severity:
  - Issue:
  - Impact:
  - Next fix:

## Suggested next milestone
- ...
```

## User-facing honesty rule

Do not write `done` if the project is only partially done.

Use accurate labels:

- `Complete for requested milestone`
- `Playable but needs polish`
- `Runs but not yet playable`
- `Blocked by missing external dependency`
