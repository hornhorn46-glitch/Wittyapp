# How To Play From GitHub

1. Download the repository as a ZIP from GitHub.
2. Extract the ZIP somewhere simple, for example `C:\Games\SilentExit`.
3. Run `PLAY_GAME.bat`.

On first launch the script downloads the official Godot 4.2.2 Windows executable into `tools\godot` and then starts the game. After that, the game launches immediately from the same file.

No paid services or manual Godot installation are required.
