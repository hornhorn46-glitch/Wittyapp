# Visual Direction

## Genre and mood
Serious, quiet stealth thriller in a fictional civic building after hours. The mood is tense and humane: low light, muffled sound, readable routes, and danger suggested through silhouette, shadow, and audio rather than explicit violence.

## Reference qualities
Do not copy copyrighted assets. Capture qualities only:
- integrated menu composition with a dark corridor/background scene
- readable restrained UI
- practical materials: concrete, worn paint, dark wood, metal doors
- clear path lighting and safe-zone color language

## Palette
- Primary: charcoal black, deep green-gray
- Secondary: desaturated concrete gray, aged wood brown
- Accent: muted emergency teal
- Danger/warning: dim amber and controlled red
- Background: near-black blue-gray

## UI rules
- Button shape: slim rectangular panels with subtle borders and hover fill
- Panel style: translucent dark surfaces, restrained outlines, high contrast text
- Font style: clean sans-serif using Godot defaults unless a licensed font is added
- HUD placement: small objective/status area top-left, context prompts bottom-center
- Animation style: quick fades and hover response, no arcade bounce

## Asset plan
- Needed assets: CC0 surface textures, CC0 3D props, CC0 character models, textured buttons/panels, generated WAV sounds.
- Source strategy: curated license-safe internet assets first for visible art; generated assets remain only for original audio and fallback textures.
- Temporary placeholders: avoid obvious placeholder visuals in user-facing screens; any fallback must be documented and replaced by curated assets when practical.
