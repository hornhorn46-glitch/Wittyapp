# Decisions

## Decision: Select Godot 4.x + GDScript

The repository had no existing game code, and the task explicitly recommended Godot 4.x when no base exists. Godot was selected because text scenes/scripts are practical for autonomous work, 3D stealth gameplay is supported, and headless/scripted validation is possible.

Rejected alternatives:

- Unity: heavier editor workflow and no existing Unity base.
- Browser/Three.js: convenient, but not aligned with the requested default stack.

## Decision: Generate license-safe audio and textures locally

The milestone requires real sound and textured materials with clear licensing. Procedural WAV and PNG assets were generated by `tools/generate_assets.py`, recorded in `ASSET_CREDITS.md`, and used in game.

Rejected alternatives:

- Random web downloads with unclear licensing.
- Leaving the game silent or visually bare.

## Decision: Upgrade visuals with curated CC0/PBR assets

The first playable needs to feel like a serious 3D project rather than a blockout. Curated CC0 packs from ambientCG and Kenney were added for flat PBR wall/floor/rug/wood materials, furniture/interior props, factory dressing, characters, windows, and textured UI. The older generated textures remain documented as project-owned fallback assets, while the level now uses the curated PBR assets as the primary visual layer.

Rejected alternatives:

- Continuing with generated preview textures, which looked too procedural and did not read as real brick, plaster, concrete, or carpet.
- Using unclear web assets, rejected because license safety is a hard project requirement.

## Decision: Scripted Godot tests plus Python structural validator

Testing uses a Python project validator for static coverage and Godot scripts for runtime smoke/playthrough checks. This avoids depending on a third-party test plugin while still validating actual engine startup and gameplay systems.
